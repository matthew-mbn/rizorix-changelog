# RIZORIX — история обновлений

Публичная история закрытой беты: https://matthew-mbn.github.io/rizorix-changelog/

Сайт оформлен в стиле игры: тёмный фон, бирюзовый/розовый неон, Tiny5 Duo и игровые фигуры. Полный обзор охватывает изменения после исходной 0.6.0 от 12 ноября 2026 до 0.7.6. Даты в истории — даты сохранения завершённых этапов по Москве, не обязательно время первоначальной сборки APK.

## Обновление истории

1. Добавьте новую запись `details.version` в начало блока `.timeline` в `index.html`; укажите уникальный якорь, дату и фактические изменения.
2. Перенесите отметку «НОВАЯ» на актуальную версию, обновите версию и дату в первом экране. Не удаляйте старые записи.
3. При необходимости обновите сводный обзор. Не называйте уже существовавшие функции новыми и не выдавайте результаты эмулятора за проверку физического телефона.
4. Проверьте страницу локально: `py -3 -m http.server 4176 --bind 127.0.0.1`, затем откройте `http://127.0.0.1:4176`. Проверьте узкий экран и раскрытие версий.
5. Отправьте изменения в `main`. GitHub Pages публикует корень этой ветки. Сборка и внешние зависимости не нужны.

Основной текст, навигация и записи работают без JavaScript. `site.js` добавляет раскрытие всех версий и подсветку навигации. Учтена настройка уменьшения анимации. Аналитика, cookies, внешние шрифты и сервер отсутствуют.

## Материалы
