# История RIZORIX

- Пользовательские тексты и документация — на русском.
- По постоянному решению владельца от 2026-11-15 после каждого нового релиза игры обновлять этот сайт, сохранять старые записи и готовить короткий живой Telegram-пост со ссылкой на подробности новой версии. Обычная публикация истории уже разрешена; Telegram-пост только подготавливать для пользователя, не отправлять без отдельного указания.
- Факты брать из завершённых релизов RIZORIX, а даты указывать по Москве. Не объявлять функцию новой, если она была в предыдущей сборке. Не выдавать измерения эмулятора за проверку физических телефонов.
- Стиль: тёмный фон, бирюзовый/розовый неон, Tiny5 Duo, читаемый основной текст и мобильная вёрстка. Использовать существующие файлы HTML/CSS/JS, не добавлять тяжёлый фреймворк или аналитику без необходимости.
- Публикация: `main`, корень репозитория, GitHub Pages. После отправки проверить сборку и доступную страницу https://matthew-mbn.github.io/rizorix-changelog/.
- Новая запись получает стабильный якорь вида `#v0-7-6`; короткий пост ссылается на неё. Старые якоря не менять.
- Не публиковать исходники игры, APK, приватные журналы, данные игроков, ключи или локальные настройки.
